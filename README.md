# WidgetCraft template catalogue

27 original editable widgets across Brutalist, Minimalist, Editorial, Bauhaus, Retro Pixel, Art Deco and Soft Pastel styles.

`catalog.json` describes each portable `.widget.json`, its SHA-256 and byte length, and the corresponding preview region in an actual WidgetCraft-rendered style graphic. Font and photo payloads are embedded in each portable document. Images show example data. Optional connections require their usual setup and permissions; downloaded documents retain live bindings and normal editability. No account credentials or user-created widget data belongs in this repository.

Typography notices are in `licenses/`. The portrait is fictional, previously generated/reviewed artwork. Quotation, vocabulary, decorative shapes, initials, mood and reading-page values are authored examples. Automatic dictionary or mood sensing is not claimed. This catalogue is suitable for public/free distribution; public GitHub files are publicly downloadable.
